# Django docker_compose HW_34.2
 
## Описание:

Проект Django - это приложение на Python.

## Задание

Опишите файл docker-compose  для запуска всех частей проекта единой командой.

## Запуск веб-сервера в терминале

````
python manage.py runserver
````

## Главный адрес

````
http://127.0.0.1:8000/
````

## Адрес админки

````
http://127.0.0.1:8000/admin/
````
